# house-price-prediction using Machine Learning

This project predicts house prices based on various features using machine learning algorithms.

## Libraries Used
- 'pandas' :  Data handling
- 'numpy' : Numerical computations
- 'matplotlib', 'seaborn' :  Data visualization
- 'scikit-learn' : Machine Learning models and evaluation
- 'joblib' : Saving trained models

## Algorithms Implemented
- Linear Regression  
- Decision Tree Regressor  
- Random Forest Regressor  
- (Optional) K-Nearest Neighbors Regressor  

 ## Features
 - Data exploration and visualization  
- Handling missing values and preprocessing  
- Splitting dataset into train and test sets  
- Training multiple regression models  
- Model evaluation using accuracy metrics
- Saving trained models with joblib

## Dataset
The dataset contains house features and their prices.  

## How to Run
1. Install required libraries  
2. Run the Jupyter notebook or Python script  
3. Train models and predict house prices
